**QuickStop Mart – Point of Sale System**



**📌 Overview**



QuickStop Mart is a C# console-based Point of Sale (POS) and Inventory Management System. It simulates a basic retail store where an employee can manage products, create sales, calculate taxes, process checkout, generate receipts, and manage a receipt queue.

The project was developed to practice Object-Oriented Programming, collections, LINQ, file handling, JSON, and asynchronous programming in C#.



**✨ Features**



* 🔐 Employee login system
* 📦 Add and manage products
* 👀 View product inventory
* 🛒 Create sales and manage shopping carts
* 💰 Calculate subtotal, tax, and grand total
* ↩️ Undo recent cart actions
* 🧾 Generate receipts
* 🖨️ Receipt processing queue
* 💾 Save and load inventory using JSON
* 🔎 LINQ-based product searching
* ⚡ Basic async/await implementation
* ✅ Input validation



**🛠️ Technologies Used**



* C#
